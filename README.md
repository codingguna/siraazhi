**தமிழ்**: **சீராழி (Siraazhi)** என்பது தென்னிந்தியாவின் பாரம்பரிய மரச்செக்கு எண்ணெய் மற்றும் இயற்கை விவசாயப் பொருட்களுக்கான ஒரு நவீன இணையதளமாகும். பழங்கால பாரம்பரியமான **வாகை மரச்செக்கு** முறையோடு அதிநவீன இ-காமர்ஸ் மற்றும் B2B டிஜிட்டல் அனுபவத்தை **React 19**, **Vite**, **Tailwind CSS v4** மற்றும் **Lucide React** போன்ற தொழில்நுட்பங்களின் உதவியுடன் ஒருங்கிணைக்கிறது.

**English**: **Siraazhi (சீராழி)** is a modern, high-performance web platform for an authentic South Indian marachekku oil brand. Siraazhi blends ancient traditional heritage—such as native **Vagai Wood Marachekku (மரச்செக்கு)** oil extraction—with a state-of-the-art e-commerce & B2B digital experience built using **React 19**, **Vite**, **Tailwind CSS v4**, and **Lucide React**.

## 🌟 முக்கிய அம்சங்கள் / Key Features

### 🌐 இருமொழி அனுபவம் (ஆங்கிலம் மற்றும் தமிழ்) / Dynamic Bilingual Experience (English & Tamil)
**தமிழ்**:
- **உடனடி மொழி மாற்றம்**: கடையின் அனைத்து பகுதிகளிலும், தயாரிப்புகளிலும், செக்அவுட் மற்றும் அட்மின் திரைகளிலும் **ஆங்கிலம்** மற்றும் **தமிழ்** ஆகிய மொழிகளுக்கு இடையே எளிதாக மாறலாம்.
- **உள்ளூர்மயமாக்கப்பட்ட தகவல்கள்**: தயாரிப்பு விளக்கங்கள், ஊட்டச்சத்து விபரங்கள், சமையல் குறிப்புகள் மற்றும் B2B விலை கணக்கீடுகள் என அனைத்தும் முழுமையாக மொழிபெயர்க்கப்பட்டுள்ளன.

**English**:
- **Instant Language Toggle**: Seamlessly switch between **English** and **Tamil (தமிழ்)** across all store sections, headers, product cards, checkout drawers, and admin views without reloading.
- **Localized Content**: Complete native translation dataset covering product descriptions, nutrition specs, recipes, trust badges, and B2B pricing calculators.

### 🛍️ ஊடாடும் தயாரிப்பு பட்டியல் & ஷாப்பிங் கார்ட் / Interactive Product Catalog & Quick Cart
**தமிழ்**:
- **வகைப்படுத்தப்பட்ட அங்காடி**: பாரம்பரிய மரச்செக்கு எண்ணெய்கள் (தேங்காய், நல்லெண்ணெய், கடலை எண்ணெய்), சல்பர் இல்லாத தூய விதைகள் (கொப்பரை, வேர்க்கடலை, கருப்பு எள்) மற்றும் சிறப்பு காம்போ பேக்குகளை ஆராயுங்கள்.
- **அளவு மற்றும் விலை**: (500 மிலி, 1 லிட்டர், 5 லிட்டர் கேன்கள், 1 கிலோ முதல் 50 கிலோ சணல் பைகள் வரை) தேர்வு செய்யும் போதே தள்ளுபடிகள் மற்றும் விலைகளை உடனுக்குடன் காணலாம்.
- **ஊட்டச்சத்து விபரங்கள்**: ஒவ்வொரு பொருளின் கொழுப்பு கலவை, ஸ்மோக் பாயிண்ட் (smoke point) மற்றும் பரிந்துரைக்கப்பட்ட சமையல்/ஆயுர்வேத பயன்பாடுகள்.

**English**:
- **Categorized Storefront**: Explore traditional marachekku oils (Coconut, Sesame, Groundnut), sulfur-free raw seeds (Copra, Peanuts, Black Sesame), and curated trio combo packs.
- **Variant Selector & Pricing**: Dynamic variant selection (500 ml, 1 Litre, 5 Litre Cans, 1 Kg to 50 Kg Jute Bags) with real-time price & savings calculation.
- **Nutrition & Smoke Point Insights**: Transparency metrics for every item, including fat composition, smoke point, and recommended cooking/Ayurvedic uses.

### 🪵 பாரம்பரிய மரச்செக்கு செயல்முறை / Traditional Marachekku Process Visualizer
**தமிழ்**:
- **4-படிநிலை செயல்முறை விளக்கம்**: கொப்பரை சூரிய ஒளியில் உலர்த்துதல், வாகை மரச்செக்கில் பிழிதல், இரசாயனமற்ற வடிகட்டல் மற்றும் சுற்றுசூழலுக்கு உகந்த பேக்கேஜிங் ஆகியவற்றை படிப்படியாக விளக்கும் காட்சி.
- **தர சான்றிதழ்கள்**: 0% சல்பர், 0g டிரான்ஸ் கொழுப்பு மற்றும் நேரடியாக விவசாயிகளிடம் இருந்து பெறப்படுவதற்கான சான்றுகள்.

**English**:
- **4-Step Craftsmanship Timeline**: Step-by-step interactive visualizer illustrating copra sun-drying, Vagai wood-pressing without heat, zero-chemical filtration, and eco-friendly bottling.
- **Quality Assurances**: Clear verification badges for 0% sulfur, 0g trans fats, marachekku-extracted purity, and farm-direct sourcing.

### 💚 ஆரோக்கியம் மற்றும் நல்வாழ்வு வழிகாட்டி / Health & Wellness Guide
**தமிழ்**:
- **மரச்செக்கு vs. ரீஃபைண்ட் எண்ணெய்**: ஊட்டச்சத்து தக்கவைப்பு, லாரிக் அமிலம், வைட்டமின் ஈ மற்றும் வெப்பத்தினால் ஏற்படும் பாதிப்புகளை ஒப்பிடும் விரிவான அட்டவணை.
- **ஆயுர்வேத குறிப்புகள்**: ஆயில் புல்லிங், அபியங்க ஸ்நானம் மற்றும் சமையல் பயன்பாடுகளுக்கான வழிகாட்டுதல்கள்.

**English**:
- **Marachekku vs. Refined Comparison**: Comprehensive chart comparing nutritional retention, Lauric acid, Vitamin E, free fatty acids, and heat degradation.
- **Ayurvedic Routine Tips**: Guidance for traditional Oil Pulling, Abhyanga oil bath, and culinary uses.

- **படிப்படியான செய்முறை**: தேவையான பொருட்கள் மற்றும் தயாரிப்பு வழிமுறைகள்.

## 🚀 பயன்படுத்துவதற்கான வழிமுறைகள் / Getting Started

### தேவையானவை / Prerequisites
**தமிழ்**: உங்கள் கணினியில் **Node.js** (v18.0.0 அல்லது அதற்கு மேல்) மற்றும் **npm** இன்ஸ்டால் செய்யப்பட்டிருக்க வேண்டும்.
**English**: Make sure you have **Node.js** (v18.0.0 or higher) and **npm** installed on your system.

### 1. இன்ஸ்டாலேஷன் / Installation
**தமிழ்**: கீழ்கண்ட கமெண்ட்களைப் பயன்படுத்தி ப்ராஜெக்ட்டை குளோன் செய்து ரன் செய்யவும்:
**English**: Clone the repository and install the project dependencies:
```bash
git clone https://github.com/codingguna/siraazhi.git
cd siraazhi
npm install
```

### 2. டெவலப்மென்ட் சர்வர் / Run Development Server
**தமிழ்**: சர்வரை ஓடத் தொடங்க:
**English**: Start the local Vite development server with Hot Module Replacement (HMR):
```bash
npm run dev
```
**தமிழ்**: சர்வர் ஓடத் தொடங்கியதும் பிரௌசரில் `http://localhost:5173` என்ற முகவரிக்குச் செல்லவும்.
**English**: Open your browser and navigate to `http://localhost:5173` (or the port specified in terminal).

### 3. புரொடக்ஷனுக்கு பில்ட் செய்ய / Build for Production
**தமிழ்**: இணையத்தில் வெளியிடுவதற்கான பில்ட்-ஐ உருவாக்க:
**English**: To build the application for production deployment:
```bash
npm run build
```

### 4. புரொடக்ஷன் வெர்ஷனை பார்க்க / Preview Production Build
**தமிழ்**: பில்ட் செய்யப்பட்ட வெர்ஷனை சோதிக்க:
**English**: To locally test the production build bundle:
```bash
npm run preview
```
